smartShift

smartShift automates SAP custom code transformation and Clean Core alignment, parsing ABAP into a semantic model and applying rule-based transformations at scale. Cited results include 5.8 million lines of ABAP made S/4HANA-compatible in six weeks and a Forrester-measured 253% three-year ROI.

Press releases (last 10 days): None found dated August 8–18, 2026 on smartShift's press page. Prior notable items sit well outside the window (AI-powered Revert to Standard; the SNP Group strategic partnership).

New product developments: smartShift AI Agents and continued Clean Core / ABAP Cloud compatibility tooling, plus published guidance on planning custom code for ABAP Cloud restrictions.

How it uses AI: The clearest mechanism in this category. smartShift parses ABAP into a language-independent meta-model, then applies deterministic transformation rules for S/4HANA compatibility — it claims 99.99% accuracy on that rule-driven path. Layered on top, Revert to Standard uses LLM-based agentic analysis, with base models fine-tuned on proprietary ABAP patterns from prior modernization projects, to identify custom code whose function is now covered by standard SAP and flag it for elimination rather than migration.

Press releases (last 10 days): None found dated August 8–18, 2026. Outside the window: Panaya launched Seemore, its agentic layer for ERP/CRM testing and change delivery, in January 2026.

New product developments: Seemore unifies change impact analysis, test management, test automation and code corrections in one intelligence layer; S/4Accelerate has been extended to cover SAP S/4HANA 2025.

How it uses AI: Panaya's core asset is a crowdsourced corpus of change and defect data from thousands of customer landscapes, which it uses to predict which objects and transactions a proposed change will affect and to scope the test set accordingly. Seemore adds a natural-language agent layer over that corpus — users describe a change and the agent returns risk assessment, generated test coverage and, for some findings, automatic code corrections.

🔧 Testing

Tricentis

Tricentis Tosca is the dominant continuous-testing platform for SAP, using model-based, scriptless test design so tests survive UI and release changes. Tosca holds certified integration with SAP Solution Manager and is sold through SAP as a Solution Extension.

Press releases (last 10 days): Yes. On August 11, 2026, Tricentis announced a veteran cybersecurity leader to oversee enterprise and product security as customers accelerate AI adoption (Tricentis newsroom). Tricentis Transform 2026 Dallas runs August 19–20 at the Arlington Convention Center.

New product developments: The Tosca Cloud August 2026 release adds the Tricentis Product Expert to in-product documentation and lets contributor-role users delete assets and folders in inventory; qTest's refreshed Manager experience became generally available in August 2026. Earlier in 2026, Tricentis shipped SAP Enterprise Continuous Testing by Tricentis with AI-assisted automated test case generation — the first SAP AI product brought to market through its Solution Extension.

How it uses AI: Two distinct mechanisms. Vision AI visually recognizes UI controls on screen rather than binding to underlying technical IDs, so tests self-heal when SAP screens change between releases. Separately, the agentic layer reads SAP process and configuration data to generate candidate test cases and test data for a given business process, reducing the manual authoring effort at the start of a conversion project. The Product Expert in Tosca Cloud is a retrieval layer grounded in Tricentis manuals.
