🔧 Security

onapsis

Onapsis sells SAP application security and compliance for S/4HANA, RISE and BTP, and its Research Labs regularly disclose SAP vulnerabilities.

Press releases (last 10 days): None. The newest release on the press page is from Oct 8. In the window, the Onapsis blog posted only a Nov 20 product piece, "Beyond the Honor System," on automated patch validation in Onapsis Assess. It announces no new feature.

The Nov 10 ICM2SHELL and PROXYGATE disclosures, covered last week, are still the main story. A Nov 11 ERP Today follow-up adds three details:

  • ICM2SHELL comes from unvalidated size values in WebSocket control messages.
  • PROXYGATE's default Gateway ACL can treat an outside attacker as an internal application server, and a profile parameter must be set after patching.
  • Onapsis had seen no active exploitation as of Nov 10.

New product developments: March 17, 2026: Onapsis Agentic Gateway. June 2026: the Q2 release, which added Web Dispatcher monitoring and one-click compensating controls. According to the Nov 20 post, Assess checks the application layer for the specific technical change a Security Note requires, such as a kernel parameter or a deactivated service, rather than trusting SNOTE's "applied" status. It can also report "Not Patched, but Workaround Applied" and lower severity accordingly. This is existing functionality, not new.

How it uses AI: The Agentic Gateway is an MCP server. Through it, approved assistants such as Copilot, Claude, Gemini, ChatGPT or custom agents can query Onapsis threat intelligence and a customer's SAP security data in natural language. They can cross-reference zero-days against the landscape and draft remediation plans. Security Advisor's "AI-powered" guidance is not explained.
