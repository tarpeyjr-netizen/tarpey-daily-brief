Panaya combines change-impact intelligence with testing for SAP, CRM, and other enterprise apps, telling teams which objects a change will actually break and which tests must run — a different angle from smartShift's bulk-remediation approach.

Press releases (last 10 days): Yes — on September 9, 2026 Panaya announced a sharpened strategic focus on autonomous enterprise testing, launching a new website, narrative, and visual identity under "Test What Matters," positioning the company as one native platform spanning test management, test automation, change-impact analysis, and custom code correction.

New product developments: The rebrand follows August 2026's general availability of Agentic Code Correction within the SAP Code Correction suite, and January 2026's launch of Seemore, an agentic layer spanning the change lifecycle from requirements through deployment.

How it uses AI: Two distinct mechanisms. Agentic Code Correction combines an LLM-based agent with Panaya's SAP domain rules and the customer's own system context to resolve complex ABAP objects, explain legacy code in plain language, and advise on Clean Core alignment, delivering an execution-ready remediation plan in roughly 12 hours. Separately, self-healing test automation autonomously analyzes the application, detects structural UI changes, and generates context-aware adaptive locators — claimed to cut automation maintenance effort up to 85% — while Seemore learns each customer's business processes to recommend test scope.

🔧 Security

onapsis

Onapsis is the category leader in SAP application-layer security — vulnerability management, code scanning, threat detection, and compliance for ECC, S/4HANA, BTP, and RISE — backed by Onapsis Research Labs, which discloses a large share of publicly known SAP vulnerabilities.

Press releases (last 10 days): Yes — SAP's September 8, 2026 Security Patch Day delivered 19 new Security Notes (plus one update), with four rated critical, five high, ten medium, and one low. The headline item is OVERPASS (CVE-2026-44756, CVSS 10.0), a maximum-severity, pre-authentication memory-corruption flaw in the SAP kernel's Extended Passport processing that Onapsis Research Labs discovered and disclosed jointly with SAP, alongside a second pre-auth kernel flaw, CVE-2026-58240.

New product developments: Just before the window, at CrowdStrike Fal.Con 2026 (August 31–September 3), Onapsis expanded its CrowdStrike partnership, integrating Onapsis Assess with Falcon Exposure Management to bring SAP vulnerability, misconfiguration, and custom-code telemetry into CrowdStrike's unified exposure model. The Onapsis Agentic Gateway, introduced earlier in 2026, remains the company's flagship "Agentic AI for SAP Cybersecurity" category play.

How it uses AI: Agentic Gateway is a translation layer, not a chatbot — it exposes SAP security and compliance telemetry to external autonomous agents (corporate AI platforms, SOC command centers, business agents) so they can query posture in natural language and act on it, on the premise that SAP telemetry (transaction codes, authorization objects, RFC destinations) is too specialized for general-purpose agents to interpret unassisted. The OVERPASS discovery itself was research- and signature-driven, not model-generated, but Onapsis is now explicitly tracking autonomous AI exploit chains against SAP as a threat category.
