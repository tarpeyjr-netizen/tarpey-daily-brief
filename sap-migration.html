How it uses AI: The core mechanism is deterministic rather than generative: smartShift parses ABAP into a language-independent meta-model (abstract syntax representation), then applies a large accumulated rule library to that model to detect S/4HANA incompatibilities, identify dead or redundant code eligible for decommissioning, and apply Clean Core-conformant rewrites. This is why it can claim near-perfect accuracy — the transformations are provable, not probabilistic. The newer AI Agents layer adds LLM-based orchestration and remediation suggestion on top of that engine; the agent layer's specifics are less documented than the meta-model core.
