ChatGPT

This Week in ChatGPT

ChatGPT is the chatbot most people picture when they hear "AI": you type, or talk, and it answers. This week it learned to do a few things that feel very grown-up. It can now pay for stuff, it got two new brains, and it got a lot better at listening.

It started on November 13 with ChatGPT Wallet. It's rolling out slowly to adult Pro subscribers in the US with a US card. Think of it like a valet key for your car. When ChatGPT's agent buys something for you, it uses a stand-in card number, so the agent and the shop never see your real one. You still check the shop, the items, the total and the card, then approve with your face or fingerprint. On November 16, OpenAI upgraded ChatGPT for Clinicians, so its medical search gets better at finding and checking real research and pointing to it. The headline came on November 17, when two new models arrived in preview: GPT-6.2 Astra and GPT-6.2 Sol. Astra is the deep thinker for hard professional work. Sol is the quick one for everyday tasks, a bit like choosing between a long essay and a quick text. Plus and Pro users can pick either one, as long as their workspace settings allow it. Then on November 18 came Live Dictation. It types out your words as you speak, and the old 10-minute recording limit is gone. It's rolling out on every plan, on phones, the web and desktop. Companies also got an Accounting plugin that can match up transactions, enter invoices and build month-end reports, once an admin says yes.

Put it together and ChatGPT is acting less like a chat window and more like an assistant that can actually get things done. That's handy. It also means the boring-sounding safety steps, like approving every purchase yourself, matter more than ever.

OpenAI Codex

This Week in OpenAI Codex

Codex is OpenAI's coding agent. Picture a helper that lives in your terminal, the text window programmers type commands into, and can read, write and fix code for you. Last week it got a pile of fun extras. This week it got new brains, and it learned to work from almost anywhere.

It kicked off on November 13, when Codex CLI 0.169.0 followed 0.168.0 on the same day. Side chats can now sit in several tabs, like browser tabs, and they're still there after you restart. You can also search old tasks in the agent command center by name, by what you asked, or by folder. Developers can add their own AI providers right from the terminal too. On November 17, the new GPT-6.2 Astra and GPT-6.2 Sol models landed in Codex. Astra is for the really hard projects. Sol is for everyday coding and writing. People on the top Pro plans get an "Ultrafast" mode, which is basically the express lane. Version 0.170.0 arrived on November 18 and added live voice calls inside the terminal. The iPhone app got an update the same day, so side chats save to a paired computer and you can pick whether a task runs in the cloud or on your own machine. Then today's 0.171.0 makes Sol the default model and turns the split-screen workspace on for everyone. It also adds undo and redo while you type a prompt, plus new /remote commands that let you pair a device and steer Codex from somewhere else.

It's like your coding helper got a walkie-talkie. You can start a job on your laptop, check in from your phone, and talk to it out loud. Next up is seeing whether Sol is smart enough as the default, or whether people keep switching to Astra for the tough stuff.

Anthropic Claude Code

This Week in Anthropic Claude Code

Claude Code is Anthropic’s coding helper that lives in your terminal. You tell it what you want in plain English, and it reads your project, writes the code and runs the commands. It ships updates almost every day, and this week it put out five of them. The most interesting one teaches Claude a new way to use its own tools.

That one landed on November 12. Version 2.1.323 added an experimental, opt-in feature called Code Mode. Normally Claude uses its tools one at a time, like asking a friend to hand you each Lego brick separately. In Code Mode, Claude writes a little JavaScript program that calls the tools for it, more like handing your friend the whole instruction booklet. The same update let plugins say which versions of Claude Code they work with, so a mismatched plugin simply won’t load instead of breaking things. Code Mode kept growing after that. On November 16, version 2.1.326 let it work alongside agent teams, where several copies of Claude split up a big job. Then on November 18, version 2.1.328 dropped a three-quarter-second pause that came after most of its scripts in auto mode. That same release made auto mode the starting setting for interactive sessions on Opus 4.6 and Sonnet 4.6 across big cloud platforms like Amazon Bedrock and Microsoft Foundry, as long as no permission mode is set. It also tidied up /code-review. On most models it now reports only real bugs and broken project rules, and it tags each finding as Important, Pre-existing or Nit. Style cleanups moved over to /simplify. In between, the locks got tighter. Version 2.1.325 on November 13 fixed a security problem in how compressed web responses get unpacked, and 2.1.327 on November 17 let you feed connection settings in through a pipe so secret tokens don’t sit in plain view on the command line.

The so-what is that Claude Code is quietly changing how it thinks about tools, from tapping one button at a time to writing its own little scripts. A date to remember is November 30, when fast mode for the older Opus 4.8 model switches off for good.

Xai Grok

This Week in Xai Grok

Grok is the AI from xAI, the Elon Musk company that now sits inside SpaceX. Last week its team helper, Grok Bot 1.0, officially launched. This week was less about new launches and more about showing what those bots can actually do at work.

The best example came from xAI itself. On November 16, the company posted a case study called “Building an accounting team with Grok Bot,” as reported by explainx.ai. It describes five bots handling the money side of the business. One sets up customer accounts once contracts are signed. Another sends invoices. A third answers billing questions in Slack, one checks incoming payments twice a day, and the last helps with collections and refunds. Meanwhile, Grok Build, xAI’s coding tool for the terminal, kept up a fast pace. Release trackers list seven new versions between November 12 and 18, from 1.0.84 to 1.0.90. The public notes for those versions don’t spell out what changed, though.

The bigger story is that xAI is trying to prove Grok can be a coworker, not just a chat window. Elon Musk said on November 10 that training on the next model, Grok 4.8, was finished. So the next headline might be a smarter brain for all those bots. There’s no release date yet.

DeepSeek

This Week in DeepSeek

DeepSeek is the Chinese AI lab famous for building strong models cheaply and giving a lot of them away. After a sleepy few weeks, it woke up on November 13 with a release it calls the Full-Suite App API. The short version: everything the DeepSeek chat app can do, developers can now plug into their own apps.

Think of it like a restaurant that used to sell only meals, and now sells its whole kitchen too. Its speedy V4.1-Flash model now comes with built-in tools you switch on with a single setting. It can search the web and show its sources. It can do “deep thinking search,” reading pages while it works through a hard problem step by step. It can read PDFs, Office files and images you hand it, and it can open links you paste into a message. DeepSeek’s servers do the fiddly work of calling those tools behind the scenes. There are also separate APIs for search, page fetching, reading text from images, turning speech into text and turning text into speech. There is a catch, though. Any app the public can use must switch on DeepSeek’s safety checks, and the tools cost extra on top of the normal per-word fees. DeepSeek also shared a free, open-source demo of a chat app on GitHub, so builders can see how all the pieces fit together.

So what? Until now, building your own “ChatGPT with web search” meant wiring up lots of parts yourself. DeepSeek just made that a few switches. Expect a wave of small apps quietly running on DeepSeek under the hood, and expect rivals to feel the pressure on price again.

Developers and researchers are the main audience, though anyone can try it in the Kimi app. Just remember many of those scores come from Moonshot’s own tests.

Cursor

This Week in Cursor

Cursor is a code editor with AI agents built in. You describe what you want, and the agents write, test and fix the code with you. This week brought one fun new feature and one serious bit of homework.

The fun part landed on November 10, when Cursor Projects went multiplayer. Projects, which launched in September, used to be a solo space. Now you can invite teammates. Everyone gets a shared task board showing who is working on what and what each person’s agents are up to. Each person still has a private chat, but decisions and design docs live in a shared layer every agent can read. The neat twist is that the agents talk to each other. If yours and a teammate’s are about to change the same database, they can agree on an order first, like two movers deciding who carries the couch through the door. When someone new takes over the on-call shift, their agent can pick up the work already in progress. It is in beta and rolling out to everyone.

The serious part came on November 13, when Cursor posted an update on a recent security incident. An attacker got hold of an access key Cursor had given to Fireworks, one of its AI partners, and copied stored coding-session records, mostly from 2025. Cursor says users in Privacy Mode were not affected. Fewer than 0.05% of other users had their records exposed, and those people were contacted directly. The attacker also slipped fake copies of Anthropic’s Claude Code extension into Cursor’s extension store for about 11 hours on October 29. Cursor says the last attacker activity it saw was on November 1. Since then it has swapped out its passwords and keys, rebuilt the extension store and added scanning that catches leaked passwords.

The takeaway is simple. If Cursor emailed you, change the keys it listed. If you installed Claude Code versions 2.1.312 or 2.1.313 from Cursor’s store, follow Cursor’s October 29 cleanup steps. Then go enjoy coding with your friends, and your friends’ robots.

This Week in OpenAI Codex

Codex is OpenAI's coding agent. Picture a helper that lives in your terminal, the text window programmers type commands into, and can read, write and fix code for you. This week it shipped updates almost every other day, and together they make the terminal feel a lot less like a plain black box.

It started on November 6 with Codex CLI 0.167.0. The headline was an "agent command center," which works like a mission-control screen for all your running AI helpers. It even marks which ones have unread results waiting, a bit like unread texts. The same release let you switch between connected backends from the session picker, preview images you attach right in the terminal, and set up Google Cloud's Vertex AI with a guided wizard. Smaller fixes followed on November 10 and 11. One of them makes Codex send tool updates bit by bit by default on Vertex AI, and anyone who wants the old way can switch it back. On November 10 the iPhone app got some Codex-friendly upgrades too. You can now paste images and files into the full-screen composer, dictate notes on your annotations, and switch drives when picking a folder on a Windows computer.

Then today brought version 0.168.0, the most playful one yet. You can open a side conversation next to your main chat in panes you can resize, attach audio recordings when you're using a model that understands sound, and, if you switch on an experimental setting, generate or edit animated GIFs. It even shows image previews and "pets" inside tmux on the Ghostty and Kitty terminals. That's a lot of polish for one week. The takeaway: OpenAI wants Codex to feel like a full workspace, not just a code robot, and it's adding pieces fast.
