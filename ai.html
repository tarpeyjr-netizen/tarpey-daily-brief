Anthropic Claude Code

This Week in Claude Code

Claude Code is Anthropic's command-line coding assistant — instead of chatting in a browser, you point it at your actual codebase and it reads, writes, and fixes files right there in your terminal, like having a fast, patient junior engineer sitting next to you.

The biggest headline this week: Claude Opus 5 is now the default model behind Claude Code's Opus mode, bringing faster responses and a much bigger memory for large codebases — like upgrading from a backpack to a suitcase for how much context it can carry while it works. Right alongside that, the "/code-review" command now runs quietly in the background as its own subagent, so asking Claude to review your pull request no longer clogs up your main conversation — it's like sending a coworker off to proofread while you keep typing. There's also a batch of smaller but meaningful fixes: permission-check bypasses got patched, PowerShell and Bash commands got safer, and a nasty bug where pressing the left arrow key could accidentally wipe out an entire conversation with no undo has been fixed — now it just asks you to confirm first.

On the accessibility side, Claude Code added richer screen-reader announcements for deleted text, and fixed a strange Windows bug where file paths with certain special characters were getting scrambled into Chinese characters, making those files impossible to open. Under the hood, Anthropic is also rolling out support for a newer, more secure version of the Model Context Protocol — the system that lets Claude Code plug into other tools — with stronger login security and new features aimed at enterprise teams.

None of this is flashy on its own, but it adds up to a tool that's steadily getting faster, safer, and less likely to eat your work by accident — exactly what you want from something that's editing your real code.

Xai Grok

This Week in Grok

xAI had one of its busiest stretches in a while. While everyone waits for that, xAI kept shipping upgrades to what's already out. Grok Build, its coding tool (in the same category as Claude Code), picked up a smarter command-line interface, an opt-in tutorial for new users, quicker bug-fixing through an improved "/doctor" checkup command, and better handling of voice, images, and its plugin marketplace.

Grok's voice features got a real upgrade too — a new speech-to-speech model called grok-voice-think-fast-2.0 launched, and it's set to become the default voice model in early August. Users can now also clone a voice from just a short audio clip and reuse it across both text-to-speech and speech-to-speech, building their own little library of voices in the xAI console. And if you're a Tesla owner, this is the week Grok started taking over your car: a software update is rolling out that lets drivers make calls, play music, adjust the climate, and even pop open the glovebox, all just by talking — no touching the screen required.

Between the model roadmap, the coding tool updates, and cars you can now boss around with your voice, xAI is clearly betting that Grok's future is less about typing and more about just talking to it directly in whatever you're already doing.

Anthropic Claude Cowork

This Week in Claude Cowork

Claude Cowork is Anthropic's take on an AI assistant that lives inside your actual workday — the kind of helper that opens files, drafts emails, and chips away at busywork like a coworker who never needs a coffee break. Up until now, it mostly lived on one desktop at a time. That just changed.

The headline news this week is that Cowork is moving to the cloud, which sounds technical but means something simple: your sessions and files now follow you. Anthropic is rolling out web and mobile versions alongside desktop, so a task you started on your laptop can keep going on your phone, and it'll start with Max plan subscribers before spreading to more plans. Tucked inside that shift is a beta feature called Remote Sessions, which lets scheduled tasks keep running even when your laptop is closed and offline — though Claude will still pause and ask for your okay before it actually sends anything or hits "submit" on your behalf, so it's more like a very diligent intern than an autopilot. Cowork also picked up write access to Microsoft 365, meaning it can now draft and send email, manage calendar invites, and create or update OneDrive and SharePoint files directly. On the smaller, quieter side, there's a new Monthly Recap under Settings, which shows you what topics ate up your time and when you're most active, plus optional break reminders and quiet hours if you'd rather Cowork not ping you at midnight.

Put together, this is Anthropic betting that people don't want an AI assistant chained to one machine — they want one that just shows up wherever they are, does the boring parts responsibly, and checks in before it acts on their behalf.

Copilot also picked up broader access to MCP agents — a kind of universal plug for connecting AI to outside tools — across Word, Excel, PowerPoint, Outlook, and Catalyst, plus tighter controls over which connectors and permissions those agents can actually touch.

On top of that, Copilot Chat now serves up richer Bing web-answer cards directly in conversation, there's a new customizable landing page for an Employee Self-Service agent, fresh admin controls for AI video generation, and easier one-click sharing of agents straight into Teams. Microsoft even renamed its Copilot Studio certification track to "Microsoft 365 Copilot specialization," swapping out an old admin exam for new agent-building credentials, which tells you where the company thinks the real skill gap is right now.

Put together, this is Microsoft betting hard that the future isn't one giant AI, but thousands of small, purpose-built agents that regular employees build and share like office memos. If that bet pays off, using AI at work starts looking less like typing into a chatbot and more like browsing an internal app store for exactly the helper you need.

Microsoft Project Perception

Project Perception is Microsoft's new AI tool for finding and fixing security holes before hackers do. Point it at a company's code, cloud infrastructure, or even its own AI systems, and it scans for vulnerabilities, then suggests — or in some cases automatically applies — a fix. What makes it unusual is how it thinks: instead of relying on one AI model for everything, it routes each task to whichever model handles it best, picking between Microsoft's own models, OpenAI's, and even Anthropic's, depending on how complex the problem is. That keeps costs down without dumbing down the hard stuff.

It matters because it puts Microsoft in direct competition with Anthropic's own security tool, Mythos, kicking off what looks like a real arms race in AI-powered cybersecurity. Enterprise security teams drowning in vulnerability reports are the obvious audience, but the genuinely surprising part is that Microsoft is happy to route tasks through a rival's model if it does the job better and cheaper — a reminder that even fierce AI competitors still quietly rely on each other under the hood.

Claude Code is Anthropic's command-line tool that lets developers hand off actual coding work to Claude instead of typing every line themselves — think of it as a very capable junior engineer who lives in your terminal.
