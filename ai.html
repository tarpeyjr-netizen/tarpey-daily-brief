ChatGPT

This Week in ChatGPT

ChatGPT is OpenAI's chatbot, the one that started the whole AI craze, and this week it got a big makeover. The headline is GPT-6, a new model that arrived on October 7 along with something called Intelligent UI, per TechCrunch.

Instead of only typing back walls of text, ChatGPT can now build little interactive tools right inside the conversation, like a calculator, a bill splitter or even a simple game, according to 9to5Mac. Imagine asking how to split a dinner check and getting a working app instead of a paragraph. It rolled out first to paid plans, with Free and Go users getting it starting the next day, and GPT-6 can also start answering while it is still thinking, then add more as it finds it. Then on October 15, a new voice model called GPT-Live-1.1 (plus a smaller one called Quip) began rolling out in ChatGPT Voice with more natural accents across languages, and earlier in the month a "Try on" button for clothes and the Finances feature for U.S. Free users arrived, as listed in OpenAI's release notes.

The big idea is that chatbots are turning from talkers into builders. Watch for how many of these interactive screens show up in everyday apps.

This Week in Anthropic Claude Code

Claude Code is Anthropic's coding helper that lives in your terminal, and it ships updates so fast it is almost like a video game getting a patch every day. Since last Thursday, the version number has climbed from 2.1.293 to 2.1.296, with nine releases landing in the first nine days of October.

The biggest headline is a new default brain: Claude Haiku 5.5, the speedy and cheaper model, now runs the show out of the box, and it comes with a huge one-million-token memory window. Earlier in the month Anthropic also made plugins easier to install straight from marketplaces and gave you more say over how hard sub-agents work. The pattern is clear: Claude Code is becoming less of a single assistant and more of a team you manage, with better guardrails. Expect more control knobs soon. (These details come from a third-party release tracker, so check Anthropic's official changelog for the fine print.)

🔍 Tool Spotlight

🔍 Tool Spotlight: EmbeddingGemma 2

Here is a model most people will never chat with, yet it could quietly power apps you use. EmbeddingGemma 2 is a Google DeepMind model released on October 6, built on the Gemma 4 design and shared openly under an Apache 2.0 license. It is an embedding model, which means it turns things into lists of numbers so a computer can tell which ones mean similar stuff. Think of a giant library where books about the same idea get shelved together, no matter the language or format.

The surprise is how much it handles. Text, code, images, video and audio all land in one shared space, so a search for a phrase can find a matching video clip. At about 740 million parameters, the quantized version needs only around 567 MB of memory on a phone, and it now reads up to 8,000 tokens at a time. That makes private, offline search and smart assistants on your own device far more realistic. Developers building search, recommendation or note-taking apps are the obvious users.

So what does it mean for you? Cheaper small models mean more apps can afford to use AI everywhere, and a defender-focused push suggests AI companies know the same smarts that help fix bugs could be used to find them. Expect both stories to keep growing.

Perplexity AI

This Week in Perplexity AI

Perplexity is the AI answer engine that gives you a straight reply with sources attached, instead of a page of blue links. Lately it has grown into something bigger, with an agent called Computer that can go off and do multi-step tasks for you.

The big news this week is about teamwork. On October 12, Perplexity explained how Projects work: shared workspaces where people and AI agents tackle long jobs together. Imagine a shared school locker that remembers everything everyone put in it. Under the hood, every project is backed by a Git repository, the same kind of save-history system programmers use, so work survives even if an agent crashes, several agents can edit at once without trampling each other, and you can roll back mistakes.

Perplexity says it is quick, too. Saving changes takes under two seconds in the typical case, and fewer than 2 percent of saves collide and need redoing. It also shared a test where agents that explored files like a person flipping through a folder beat the usual search-based approach on 150 finance questions. Earlier in the month, the company's blog also showed new research on image-and-text search models and a partnership with American Express to bring business tools to growing companies.

The so-what: AI is moving from a chatbot you ask one question to a coworker that remembers what happened yesterday. Projects is Perplexity's bet on that future.

🔍 Tool Spotlight

🔍 Tool Spotlight: GLM-5.3 Fast

GLM-5.3 Fast is a speedier version of GLM-5.3, the model from Z.ai, the Chinese AI lab also known as Zhipu. It showed up on October 7 and, according to the LLM Gateway listing, does the same work as the regular model but produces answers about one and a half to two times faster. That is a bit like a sports car that is the same car with a better engine tune.

It matters because speed is what makes AI feel usable. Slow answers kill the flow when you are coding or running an agent that makes dozens of calls in a row. The listing shows a huge one-million-token memory, meaning it can hold a very large pile of text in mind at once, at roughly $2.80 per million input tokens and $8.80 per million output tokens. Developers and teams building coding tools are the obvious users. The surprising bits: the base GLM-5.3 reached the world in August with its weights held back for a safety review, and the fast version is so new that only one provider serves it and some features, like tool calling, are missing through that route. Details are still sketchy, so treat it as one to watch.

ChatGPT

This Week in ChatGPT

ChatGPT just got a makeover in how it talks back to you. On October 7, OpenAI began rolling out GPT-6 along with something called Intelligent UI, and it’s a bit like going from texting to a mini app.

Instead of only giving you paragraphs, ChatGPT can now drop interactive pieces right into its answer: charts you can explore, buttons, forms, diagrams, maps, even little calculators. Ask it to compare two phones and you might get a table you can poke at; ask what time it is in Tokyo and you’ll still just get a sentence. The idea is that the format fits the question. Paid plans use a model called GPT-6 Sol for this, while Free and Go users get its smaller sibling, GPT-6 Luna, with the rollout reaching them on October 8. It’s phased, so you may not see it yet, and you can ask for fewer visuals if it gets flashy.

One catch: this is for the regular Chat tab only. The models behind ChatGPT’s Work mode and Codex are separate. If the experiment works, chatting with an AI could start to feel less like reading and more like using software that builds itself around your question.

Le Chat / Mistral

This Week in Le Chat / Mistral

Mistral is the French AI lab that likes to prove Europe can build giants too, and this week it showed off its biggest one yet. On October 6 it introduced Mistral Large 4, a new flagship model that the company nicknamed “le Chonk.”

“Chonk” is fair. The model has about one trillion parameters in total, but it’s built as a “mixture of experts,” which is like a huge team of specialists where only a handful, about 52 billion parameters’ worth, step in for each word. It can read images as well as text and can switch between quick answers and step-by-step reasoning. Mistral says it trained it from scratch on thousands of NVIDIA chips in European data centers, and it’s available now as a preview in Mistral Studio, with the open weights, the files you can download and run yourself, promised by the end of October. The scores are Mistral’s own, so treat them as bragging rights until others test them, but the company reports strong results on coding and agent tasks and says human raters ranked it second of five on coding quality.

This model comes right after the company’s September news: a €3 billion funding round, a new hub in Munich focused on industrial AI, and a partnership to put its models in Firefox. Watch for the open weights: if they land on time, anyone will be able to run a trillion-parameter model from Europe.
